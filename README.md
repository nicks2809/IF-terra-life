## ✨ 핵심 시스템 및 특징

### 1. 내러티브 탄생 설계 및 고정 시드(Seed) 재현
- 접속 즉시 시간이 흐르지 않고, 테라 세계관 규칙 안내와 함께 **이름(무작위 주사위 지원)·성별·출생 국가**를 직접 고르거나 **원작 인구통계 가중치 기반 무작위 출생**으로 삶을 시작할 수 있습니다.
- **고정 시드(Custom Seed)** 코드를 입력하면 동일한 출생 환경, 초기 역량, 운명 분기를 그대로 재현하거나 타인과 공유할 수 있으며, 진행 중인 생애는 자동 저장되어 언제든 이어할 수 있습니다.

### 2. `1년 = 1분` 실시간 생애 호흡 & 사계절 순차 서사
- **1시간의 장편 일대기**: `x1` 배속 기준 **1년은 1분(60초)**이며, 60년 생애 완주 시 약 1시간의 실시간 호흡으로 진행됩니다 (`x1` · `x2` · `x4` · `x8` · `x16` · `x32` 6단계 배속 및 일시정지 지원).
- **사계절 랜덤 시차 배출**: 1년치 로그가 연초에 한꺼번에 쏟아지지 않고 **봄·여름·가을·겨울** 흐름에 맞춰 연중 자연스러운 시차로 한 줄씩 기록됩니다. 사건이 없는 평온한 해에는 국가와 계절의 정취를 담은 **일상 한 줄**이 남습니다.
- **선택의 무게**: 운명을 가르는 **중대한 선택지**에서는 시간이 자동으로 멈추며, 스쳐 지나가는 **작은 선택지**는 시간을 기다려 주지 않고 흘러가거나 `[0] 흘려보내기`로 넘길 수 있습니다.

### 3. 테라 16개 국가·세력별 동적 UI 테마 및 고유 위젯
- 태어난 국가 또는 현재 소속 세력(**염국, 우르수스, 빅토리아, 컬럼비아, 사르고, 라이타니엔, 카시미어, 이베리아, 시라쿠사, 림 빌리턴, 사미, 라테라노, 용문, 카즈델, 쉐라그, 로도스 아일랜드**)에 따라 화면 팔레트, 전용 벡터 휘장, 터미널 헤더 타이틀, 좌·우 사이드바 배치가 동적으로 변화합니다.
- 각 국가의 설정을 반영한 **16종 실시간 고유 지표 위젯**(빅토리아 증기 압력·귀족원 의석, 라테라노 헤일로 공명 주파수, 카시미어 기사 배당률, 이베리아 해사 조석 경보, 사미 붕괴 침식도 등)이 국가별 고유 위치에 표시됩니다.
- 상단 전환 버튼으로 사이버네틱 **PRTS 터미널 뷰**와 양피지 감성의 **테라 역사 총서(고서적) 뷰**를 언제든 오갈 수 있습니다.

### 4. 광석병 병리·전술 전투·인연과 업적
- **종족 및 광석병 병리 시뮬레이션**: 살카즈(웬디고·뱀파이어 등 고대 혈통 포함), 산크타, 쿠란타, 에기르, 루포, 우르수스 등 종족별 기대·한계 수명과 함께 체세포 결정화율(`%`), 혈중 오리지늄 농도(`u/L`), 병변 부위, 억제제 투여를 정밀하게 추적합니다.
- **자율 행동·전투·직군 승급**: 연간 행동력(`AP`), 4대 연간 집중 태세, 암시장·무기고 장비 장착, 특수 직군 임관 심사, 강적 조우 시 열리는 **미니 턴제 전술 전투**, 위기 상황에서 목숨을 구해주는 **동료 인연**, AI 자동 선택 모드를 지원합니다.
- **영면 기록 및 공유**: 생애 종료 시 최종 종합 점수(`S ~ F` 랭크), **17종 도달 엔딩**, **95종 업적 도감**, 추모실 영구 기록(`localStorage`)과 함께 **추모 카드 PNG 이미지 저장** 및 텍스트 복사를 지원합니다.

## ⌨️ 키보드 단축키

| 단축키 | 동작 |
| :---: | :--- |
| `Space` | 자동 진행 일시정지 / 재개 *(중대 선택지 대기 중에는 선택 우선)* |
| `[` / `]` | 배속 낮추기 / 높이기 (`1x` ↔ `32x`) |
| `1` ~ `4` | 활성 사건의 1~4번 선택지 즉시 선택 *(평상시 배속 단축키로 동작)* |
| `0` | 작은 사건 선택지 흘려보내기 |
| `N` | 수동으로 다음 해(`+1년`) 즉시 진행 |
| `S` | 다음 선택지(사건)가 나타날 때까지 즉시 건너뛰기 |

## 🛠️ 기술 스택 및 로컬 실행

- **Frontend**: React 18, TypeScript 5, Vite 5, Tailwind CSS 3, Lucide React
- **Persistence & Export**: Browser `localStorage`, `html-to-image`, `canvas-confetti`
- **Deployment**: GitHub Actions → GitHub Pages 자동 빌드·배포

```bash
# 의존성 설치
npm install

# 로컬 개발 서버 실행
npm run dev

# 프로덕션 빌드 및 검증 스위트 실행
npm run build
node scripts/e2e-test-runner.mjs
node scripts/verify-simulation.mjs
```
