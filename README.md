# 테라의 한 사람으로 태어나 (Terra: Life in Arknights)

> **"박사님, PRTS 가동을 시작합니다. 테라의 한 사람으로서 살아가는 여정에 오신 것을 환영합니다."**  
> *"우리는 황야에서 태어나, 재앙의 눈을 마주하고, 오리지늄의 침식을 견디며 역사의 한 조각이 된다."*

Project Moon의 명작 텍스트 인생 시뮬레이터 ['도시의 한 사람으로 태어나'](https://project-moon-life.cityborn.workers.dev/)에서 영감을 받아, **명일방주(Arknights)** 세계관인 **'테라(Terra)'**를 무대로 제작된 **텍스트 & RPG 하이브리드 인생 시뮬레이션 웹 게임**입니다.

플레이어는 14개 이상의 종족(살카즈, 산크타, 쿠란타, 루포 등), 12개 국가(용문, 우르수스, 카즈델, 빅토리아 등), 그리고 다양한 신분과 감염 여부를 무작위로 부여받아 테라의 한 복판에 태어납니다.  
체력과 이성을 지키고, 오리지늄 아츠를 수련하며, 때로는 광석병의 가혹한 침식과 싸우며 역사의 대사건 속에서 자신만의 일대기를 완성하세요.

---

## 🌟 핵심 특징 (Key Features)

### 1. 테라에서의 무작위 출생 (Random Origins)
- **14개 이상의 종족 및 고유 생체 패시브**:
  - **살카즈 (Sarkaz)**: 원초의 혈맥을 통한 아츠 친화력과 강력한 체력, 그러나 높은 감염 위험과 사회적 차별.
  - **산크타 (Sankta)**: 수호총 사용 면허와 동족 간의 공감각(The Law), 엄격한 율법.
  - **쿠란타 (Kuranta)**: 질풍의 기동성과 카시미어 기사도 전승.
  - **에기르 (Aegir)**: 뛰어난 신체와 질병 저항력, 오리지늄 아츠의 부재와 '심해(시본)'의 부름.
  - **루포, 펠린, 우르수스, 리베리, 포르테, 카프리니, 엘라피아** 및 희귀 고대종(**드라코, 아슬란**).
- **12개 국가 & 5개 거주 환경**:
  - 용문, 우르수스, 빅토리아, 컬럼비아, 카즈델, 라테라노, 이베리아, 카시미어, 사미, 쉐라그, 시라쿠사, 염국
  - 이동도시 상류층 / 일반 구역 / 슬럼가 / 황야 노마드 / 이동기지(로도스 등)

### 2. 정밀한 광석병(Oripathy) 4단계 병리 시뮬레이터
- **체세포 오리지늄 결정화율(%)**과 **혈중 농도(u/L)**, **주요 병변 부위(폐, 신경계, 사지 등)**를 정밀 관리합니다.
- **양날의 검**: 감염률이 증가할수록 오리지늄 아츠의 파괴력이 1.5배~3.5배까지 폭증하지만, 신체 붕괴와 정기적인 이성 소모, 그리고 100% 도달 시의 **결정화 파열 사망**이라는 치명적인 대가를 치러야 합니다.
- 로도스 아일랜드의 정품 억제제를 제때 투약하거나 암시장 불법 복제약의 부작용을 감수해야 합니다.

### 3. 하이브리드 시간 제어 & 연간 자율 활동
- **하이브리드 템포**:
  - 기본 1분=1년 실시간 자동 진행 + 1x/2x/4x 배속 + 일시정지 + **[다음 해로 >]** 수동 턴 스킵 버튼 지원.
- **연간 자율 활동 (Annual Free Actions)**:
  - 매년 주어지는 활동 포인트를 통해 원하는 행동을 직접 지휘합니다:
    1. **오리지늄 아츠 수련**: 속성 아츠(열량, 전격, 중력, 정신 등) 영창 습득
    2. **전술 훈련 & 암시장 파밍**: 무기/방어구 강화 및 암시장 희귀 장비 구매
    3. **진영 의뢰 수주**: 로도스 구조 임무, 용문 치안 보조, 펭귄 로지스틱스 비밀 배송, 카즈델 용병 계약
    4. **의료 및 광석병 치료**: 로도스 이동 진료소 방문 및 정기 억제제 투약
    5. **휴식 및 이성 회복**: 시에스타 음악제, 라이타니엔 오페라, 쉐라그 온천 요양

### 4. 테라 역사 타임라인 & 미니 턴제 배틀 모달
- **테라 대사건 라디오 속보**: 체르노보그 사변(1096), 용문 사변(1097), 카시미어 메이저 기사 대회(1097), 라인 랩 사건(1098), 런디니움 위기(1099), 이베리아 해사 침공 등 실제 연도별 역사적 사건이 전역 뉴스로 울려 퍼집니다.
- **미니 턴제 배틀 모달 (Tactical Combat Modal)**:
  - 보스급 적(살카즈 백부장, 리유니온 지휘관, 해사 침식체 등)과 조우 시 화면 중앙에 배틀 모달이 팝업됩니다.
  - `[물리 공격]`, `[오리지늄 아츠]`, `[전술 방어/회피]`, `[전술 약품 사용]` 커맨드를 통해 전략적인 전투를 지휘합니다.

### 5. 듀얼 비주얼 테마 시스템
- **PRTS 터미널 테마 (기본값)**: 흑연 카본 배경, 로도스 일렉트릭 시안(#00e5ff), 하저드 옐로우, 심전도(ECG) 바이탈 모니터 애니메이션.
- **테라 역사서 고서적 테마 (전환 토글)**: '도시의 한 사람' 스타일의 앤틱 양장본 양피지 텍스처, 송명(Song Myung) 폰트, 빈티지 만년필 잉크 감성.

### 6. 영구 보존 & 추모실 (Hall of Fame)
- 사망 시 심전도 플랫라인과 함께 **PRTS 최종 사망 보고서 및 묘비명(Epitaph)** 렌더링.
- `IndexedDB`를 통해 브라우저에 과거 플레이한 모든 인물들의 일대기 영구 보존.
- 1클릭 SNS 공유용 추모 카드 PNG 이미지 다운로드 및 클립보드 텍스트 복사 지원.

## 🛠️ 기술 스택 (Tech Stack)

| 구분 | 기술 스택 | 설명 |
| :--- | :--- | :--- |
| **Frontend** | React 18 / TypeScript / Vite | 현대적인 고성능 SPA 아키텍처 |
| **Styling** | Tailwind CSS / Lucide React | PRTS 터미널 및 테라 고서적 듀얼 스타일링 |
| **Storage** | LocalStorage / IndexedDB | 과거 생애 도감 및 세이브 데이터 영구 보존 |
| **Export** | html-to-image / Canvas-confetti | 추모 카드 PNG 렌더링 및 클립보드 공유 |
| **CI/CD** | GitHub Actions / GitHub Pages | Push 시 자동 정적 사이트 무료 배포 |

## 🚀 빠른 시작 (Quick Start)

```bash
# 1. 의존성 패키지 설치

npm run dev

npm run build
```
